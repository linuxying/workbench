# 个人工作台 (Personal Workbench)

一个跑在本机的个人任务管理工具：**任务看板 + 里程碑提醒 + 报表述职 + 便利贴 + 项目填报**。

纯本地运行，数据存在一个 SQLite 文件里，不联网、不上传、不依赖任何外部服务。

## 功能

侧边栏五个视图：

- **📌 任务看板**：待办 / 进行中 / 已完成三列，拖动改状态
  - 卡片 / 表格双模式；卡片支持**按项目分组折叠**
  - **紧迫度信号**：截止日按距今天数分级——逾期（红）/ 今天到期（青）/ 三天内（蓝），卡片左色条与日期标签同步变色，整列扫一眼就知道该动哪几张
  - **优先级三档**：高（琥珀顶边条 + 实心徽章 + 标题加粗）/ 中 / 低，靠填充度而非色深区分
  - **四种排序**：紧急优先（分层：逾期 → 今天 → 高优先级 → 三天内 → 其余）/ 优先级 / 截止时间 / 最近更新
  - **密度档位**：标准 / 紧凑，紧凑档只留「什么事 + 什么时候」，一屏能看完十几张卡
  - 描述按需悬停展开，不挤压卡片布局
  - **关键字检索**：输入即筛，覆盖标题 / 描述 / 项目 / 分类 / 链接 / 完成原因 / 最新进展七个字段；
    空格分词为「同时命中」语义，命中片段琥珀高亮，带命中计数与一键清空（`/` 聚焦、`Esc` 清空、
    点 ✕ 复位）；卡片与表格两种模式共用同一检索词，切换不丢上下文
  - **工具栏统计**：`共 N 项 · 已完成 N · 逾期 N`，卡片与表格两态一致；口径为**全量**，不随筛选或检索收缩（窄屏检索时让位给命中胶囊）
- **🎯 里程碑**：按时间轴看全部有时限的事项，分「节律 / 承诺 / 计划」三类语义分开提醒
  - 节律（如每月巡检）完成即自动滚到下一期，默认可提前 30 天预警
  - 承诺（客户要求的交期）逾期会明确报红
  - 计划（研发排期）滑期只提示、不报红——避免红色疲劳
  - 支持日 / 周 / 月 / 季 / 年五种重复频率，子任务承载计划阶段节点
- **📊 报表中心**：概览卡片、按项目(客户)分布、状态/优先级分布；**每日流水账**自动聚合进展记录与任务动态，支持导出**述职 Markdown**（按季度 / 年度）
- **🗒️ 便利贴**：联系人 / 流程 / 备忘三类速记
- **⏱️ 项目填报**：常用填报系统链接集中管理，一键跳转

其他：
- 任务支持**原生重复**（日/周/月/季/年），完成后自动生成下一期
- 每条任务可记**进展记录**；标记完成时弹窗记录「完成原因」与日期
- 📤 数据导出（JSON 全量 / Markdown 流水账）
- 💾 每日自动备份数据库到 `backup/`

## 技术栈

- 后端：Python (Flask) + SQLite（单文件 `workbench.db`）
- 前端：原生 HTML/CSS/JS 单页应用，**无构建步骤**，无第三方前端依赖
- 数据库：开发态 WAL 模式，打包态 DELETE 模式（保证单文件可直接拷贝迁移）
- UI：自建设计系统（Electric Cobalt 主色 + 受控 Cyber Teal 强调 + Slate 中性阶），规范见 `DESIGN.md`

## 本地启动（开发）

**前置条件**：Python 3.9+（`requirements.txt` 里 `flask>=3.0` 会解析为 Flask 3.1.x，后者要求 Python 3.9+；本机实测 3.11.9 通过）。

```bash
pip install -r requirements.txt
python workbench.py
```

或双击 `workbench.bat`（已设 `chcp 65001` UTF-8 控制台，启动后自动打开浏览器）。

启动后控制台会打印：

```console
=======================================================
  📋 个人工作台 v1.0
  📂 数据库: <项目目录>\workbench.db
  💾 备份目录: <项目目录>\backup
  📤 导出目录: <项目目录>\exports
  🌐 访问地址: http://127.0.0.1:5000
  🔘  关闭：在页面内点「退出程序」按钮（或 Ctrl+C）
=======================================================
```

浏览器访问 http://127.0.0.1:5000

自定义端口：设置环境变量 `PORT`，如 `PORT=5099 python workbench.py`（横幅里的端口会同步变化）。

> Windows 控制台默认 GBK 编码，直接 `python workbench.py` 会在打印 emoji 横幅时静默崩溃（无输出）。
> 用 `workbench.bat`（已设 UTF-8）或先 `chcp 65001` 再运行；已实测 venv 内配 UTF-8 控制台可正常启动。

## 打包为单文件 exe

免安装分发，目标机器无需 Python 环境：

```bash
python -m PyInstaller --onefile --console --add-data "templates;templates" --name workbench workbench.py
```

产物：`dist/workbench.exe`（约 10 MB，已内嵌 Flask 与前端模板）。

> 注：若构建在末尾清理临时文件时报错中止（某些受管环境的回收站钩子会拦截删除），
> 用 `python -S -m PyInstaller ...` 并通过 `PYTHONPATH` 指向 venv 的 `site-packages` 重跑即可。

## 跨电脑迁移

**推荐方式（零安装）**：只拷两个文件到新机器的同一目录

1. `workbench.exe`
2. `workbench.db`（你的数据）

双击 exe 即可，3 秒后自动打开浏览器。数据库会在 exe 所在目录读写，不会丢。

**注意事项**：
- 拷贝 `workbench.db` **前必须先关闭正在运行的工作台**，否则可能丢最近的写入
- 关闭程序 = 直接关掉那个黑色控制台窗口（或用侧边栏「⏻ 退出程序」、在窗口内按 Ctrl+C）
- 如果拷贝时发现同目录有 `workbench.db-wal` / `workbench.db-shm`，说明程序没关干净，一并拷走或先正常退出再拷

**源码方式迁移**：拷整个目录但排除 `venv/`，在新机器执行 `pip install -r requirements.txt` 重建环境。

## 测试

```bash
# 后端（使用临时空库，不会触碰真实数据）
python tests/unit_dates_kind.py      # 日期推算与字段归一化
python tests/api_kind_repeat.py      # 任务类型 / 重复 / 接口排序
python tests/api_reminders.py        # 里程碑提醒引擎

# 前端（Node VM + mock DOM，真实执行页面 JS）
node tests/vm_regression.js http://127.0.0.1:5000

# 端到端冒烟（需服务运行；会写入并清理测试数据，故默认只允许本机地址）
python tests/smoke_test.py http://127.0.0.1:5000
```

前端回归 **121 项**，覆盖看板渲染契约、紧迫度分级、排序分层、优先级视觉、描述浮层、密度档位联动、
关键字检索（七字段匹配面、AND 分词、高亮转义安全、双入口同步、零命中态、表格模式叠加），
以及工具栏统计（卡片模式填充、全量口径不随检索收缩、表格模式防回归）。

冒烟测试走完整链路（新增 → 编辑 → 记进展 → 标记完成 → 流水账 → 导出 → 清理 → 复查残留），
并巡检 `workbench.py` 里全部无参只读路由（15 个）；它会解析路由表做**清单漂移检查**，
漏探或探到不存在的接口都会失败。中途断言失败也会在 `finally` 里清掉测试数据。

## 版本

### v1.0.1

- 任务看板新增**关键字检索**：本地即时过滤（不再每键一次请求），七字段匹配面，空格 AND 分词，

- 顶栏原搜索框统一为同一套检索逻辑，两个入口双向同步，行为一致
